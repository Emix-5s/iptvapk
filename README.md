# StreamPulse Android app

A minimal Android launcher app for the StreamPulse link. It opens the supplied URL in the device's default browser and adapts its layout for Android TV, tablets, and phones.

## Build

Open this folder in Android Studio and build the `app` debug variant, or push the project to GitHub and run the **Build StreamPulse APK** workflow under Actions. The workflow uploads `app-debug.apk` as an artifact.

This environment did not have the Android SDK or Gradle installed, so an APK could not be compiled directly here.
